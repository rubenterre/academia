HTML semántico es la base de cualquier interfaz web bien estructurada. Antes de pensar en estilos o JavaScript, necesitas entender cómo representar correctamente el contenido y la jerarquía de una página.

## Qué vas a aprender

- Qué significa que una etiqueta sea semántica.
- Cuándo usar `header`, `main`, `section`, `article`, `nav` y `footer`.
- Cómo mejorar accesibilidad y SEO con una estructura correcta.
- Cómo pensar el contenido antes de diseñar la interfaz.

## Idea clave

Una web profesional no empieza por el color ni por las animaciones. Empieza por una estructura limpia, entendible y mantenible.
