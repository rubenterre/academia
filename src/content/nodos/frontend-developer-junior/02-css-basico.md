Después de construir una buena base semántica, el siguiente paso es aprender a dar forma visual a la interfaz. CSS te permite controlar jerarquía visual, espaciado, composición y adaptación a distintos tamaños de pantalla.

## Qué vas a aprender

- Selectores y propiedades fundamentales.
- Cómo funciona el modelo de caja.
- Diferencias entre Flexbox y Grid.
- Cómo empezar a construir layouts responsive sin complicarte.

## Idea clave

CSS no es decorar una página: es diseñar sistemas visuales consistentes y adaptables.
