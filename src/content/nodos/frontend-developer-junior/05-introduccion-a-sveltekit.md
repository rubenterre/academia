Con HTML, CSS, JavaScript y Git ya puedes empezar a entender cómo se construye una aplicación frontend moderna con framework. SvelteKit es una buena puerta de entrada para aprender routing, layouts y estructura de proyecto real.

## Qué vas a aprender

- Qué diferencia hay entre una web estática y una app moderna.
- Qué aporta SvelteKit sobre Svelte.
- Cómo se organiza un proyecto por rutas y componentes.
- Por qué un framework acelera el trabajo cuando la complejidad crece.

## Idea clave

Un framework no sustituye los fundamentos. Los aprovecha para ayudarte a construir más rápido y con mejor estructura.
