Aprender frontend sin control de versiones te deja cojo muy pronto. Git y GitHub forman parte del trabajo real, tanto para guardar cambios con seguridad como para colaborar y mostrar proyectos.

## Qué vas a aprender

- Qué problema resuelve Git.
- Commits, ramas y flujo básico de trabajo.
- Cómo subir un proyecto a GitHub.
- Por qué esto importa para estudiar, trabajar y construir portfolio.

## Idea clave

No basta con programar: también necesitas trabajar con orden, contexto e historial.
